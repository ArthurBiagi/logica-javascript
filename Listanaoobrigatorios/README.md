# 📝 Exercícios Complementares - Lógica com JavaScript

Este diretório centraliza a resolução dos desafios e exercícios práticos **não obrigatórios** desenvolvidos durante o módulo inicial do curso de Lógica de Programação utilizando **JavaScript**. 

O objetivo destes scripts é consolidar os fundamentos da linguagem, testar algoritmos alternativos e fixar os conceitos de controle de fluxo e manipulação de variáveis antes de avançar para estruturas mais complexas.

---

## 📌 Resumo dos Arquivos

* 📄 **[`primeiros ex N.O.js`](./primeiros%20ex%20N.O.js)**: Scripts dedicados aos primeiros testes de sintaxe, entrada e saída de dados via console/prompt, operações matemáticas básicas e validações condicionais simples (`if/else`).
* 📄 **[`exercicio 2 N.O.js`](./exercicio%202%20N.O.js)**: Exercícios focados em fixação secundária, abordando laços de repetição (como `while`), manipulação de strings e pequenos desafios de lógica propostos no projeto inicial.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem Principal:** JavaScript (Ambiente de execução/Web)
* **Ferramentas:** Visual Studio Code, Git e GitHub

---

## 🧠 Conceitos Praticados

1. **Sintaxe e Variáveis:** Declaração correta de escopos utilizando `let`.
2. **Estruturas Condicionais:** Tomada de decisão em blocos de código com base em expressões lógicas.
3. **Interação Básica:** Entrada e processamento de informações dinâmicas simuladas no fluxo do algoritmo.
